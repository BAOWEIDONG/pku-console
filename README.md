# 北大医疗 · 运营中台

三套 H5 的统一运营后台：**减重营（versionall）**、**北大医疗品牌站（PKU-introduce）**、**职工健康（pku-employee-health）**。

不依赖构建与后端，纯静态多页 SPA，可直接放到 GitHub Pages。

## 设计

- 深海军蓝控制塔侧栏 + 冷调纸面画布 + 液态玻璃浮层
- 品牌蓝 `#0B63E5`，辅以医疗青 `#0AA39A`、琥珀 `#C8871A`；珊瑚色只用于风险
- 发丝级分隔代替满屏卡片；数字用等宽数位；表格无重边框
- 桌面优先，≤1180 收起预览栏，≤940 收成图标栏

## 联动机制

后台与前端共用同一份配置：

1. 任何编辑写入 `Store`，进入「未发布变更」队列并实时重绘右侧手机预览。
2. 预览不是截图：由 `preview.js` 用当前配置渲染学员端 / 官网 / 职工端页面，开关、文案、库存、上下架立刻可见。
3. 发布中心按应用分组展示变更，可写发布说明、导出 JSON、或推送到对应仓库（`admin-config.json`）。
4. 历史订单、已领取奖励使用快照，配置变更不追溯。

## 目录

```
index.html
assets/
  app.css        设计系统与全部组件样式
  data.js        三端种子数据
  store.js       状态、持久化（localStorage）、变更队列、发布
  ui.js          图标、抽屉、弹窗、表单、表格、图表
  kit.js         页面排版原语
  preview.js     手机端同源渲染
  m-*.js         各应用页面与操作
  app.js         外壳、路由、命令面板、事件
```

## 本地运行

```bash
python3 -m http.server 8080
# http://localhost:8080
```

> 直接用 file:// 打开也可运行，但 localStorage 与部分浏览器行为以 http 为准。

## 交互

- `⌘K` / `Ctrl+K` 全局搜索页面
- 右上角眼睛图标开关实时预览
- 所有编辑走右侧抽屉，保存后进入待发布队列
- 危险操作（删除营期、取消订单、重置数据）二次确认并写明连带影响

## 接入真实后端

把 `store.js` 的 `persist/emit` 换成接口调用即可；页面层只依赖 `Store.db` 与 `Store.set/saveItem/removeItem`，无需改动业务页面。
