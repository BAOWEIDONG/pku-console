# 北大医疗 · 三端协同运营中台 v10

线上：https://baoweidong.github.io/pku-console/

这不是一个通用后台模板，而是按三个真实 H5 的页面、字段、角色与数据重建的运营中台：

| 端 | 仓库 | 后台落点 |
| --- | --- | --- |
| 健康训练营 | `versionall` | 15 个页面：营期学员、首页、打卡规则、记录批注、30 项指标、徽章、积分、连续奖励、商城、履约、活动、团队、报告、账号 |
| 品牌站 | `PKU-introduce` | 6 个页面：品牌首页、师资团队、分院网络、学科科室、健康营项目、关于北大医疗 |
| 职工健康 | `pku-employee-health` | 10 个页面：首页、28 项服务目录、服务详情、预约规则、预约记录、权益、健康档案、科普讲座、机构、五好生活、消息 |

此外提供跨产品能力：客户中心与客户 360、共享素材库、电话跟进、H5 页面对照、能力边界、发布中心、角色与日志。

## v10 的关键变化

- **按真实 H5 重建**：数据由三个 H5 的源码、页面与 mock 数据抽取生成，不再使用自造的渠道 / 商品 / 泛健康域。
- **导航始终可读**：深蓝固定侧栏，分组文字常显；按端展开当前分组，不再依赖悬浮提示。
- **三端主色区分**：健康训练营 `#f07a43`、品牌站 `#2c8aa8`、职工健康 `#ff6a13`。
- **整卡可点**：服务、专家、机构、预约、客户等列表整行 / 整卡进入详情，不再只能点最右箭头。
- **图片成为一等公民**：商品主图、多图图集、图文详情、轮播 / 活动横幅、服务主图、专家头像、机构图片都支持上传与替换。
- **客户 360**：个人信息、训练营打卡、批注、积分奖励、职工预约、权益、报告、授权、消息、备注、电话待办与全部时间线聚合在一页。
- **变更影响不跳页**：从任意页面打开抽屉，看完即可关闭回到原页面。
- **不伪装接口**：没有企业微信、短信、物流、支付、排班接口。主动触达只做电话人工待办。

## 真实生效边界

三端 H5 均已接入 `assets/pku-bridge.js`，刷新后读取 `config.json`。当前真实生效 6 类：

1. 客服电话 / 热线 / 地址文本替换
2. 职工端站点标题
3. 职工端 5 大模块显隐
4. 职工端服务上下架
5. 品牌站导航入口显隐
6. versionall 排行榜入口显隐

以下内容后台可编辑、可保存、可导出，但静态 H5 不会自动读取：轮播图、商品图集与图文、服务名称与介绍、专家与机构图片、文章正文、五好任务、预约排班、消息正文。发布中心与能力边界页会明确标注，不把“保存成功”说成“线上已生效”。

## 本地运行

```bash
cd work
python3 -m http.server 8766
# 打开 http://localhost:8766/work/pku-console/
```

数据保存在浏览器 `localStorage`，键为 `pku-console-v10`。换浏览器或清缓存会回到真实 H5 初始数据。

## 发布

1. 在「发布中心」下载或复制 `config.json`；
2. 提交到 `pku-console` 仓库并等待 GitHub Pages 构建；
3. 刷新三个 H5，检查联系方式与入口显隐；
4. 回到「H5 页面对照」核对生效状态。

仓库不保存 GitHub Token，部署只在本机使用环境变量。
